CPA2API Release v7.1.45-s.8

This release fixes a bug in model registration when multiple Codex credentials are configured.

### Key Changes:

- **Codex Model Registration Fix**:
  - Refactored `rebindExecutors` in `sdk/cliproxy/service.go` to ensure that model registration and state reconciliation are not bypassed for subsequent active Codex credentials.
  - Fixes the issue where custom configured Codex models (e.g., `gpt-5.4-mini` and `gpt-5.5` added via the Web UI manager) were not exposed under `/v1/models` in configurations containing multiple Codex credentials.
