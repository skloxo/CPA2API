CPA2API Release v7.1.45-s.6

This release fixes a bug in the management panel's check-update version comparison logic.

### Key Changes:

- **Web UI Update Check / Version Comparison Bug Fix**:
  - Refactored `compareVersions` in `SystemPage.tsx` to correctly separate the upstream version prefix from the customized patch suffix (e.g. `-s.x`).
  - The comparison logic now compares custom patch suffixes first since they represent monotonic custom releases of our fork, and falls back to comparing upstream semver segments if patch versions are equal or either version is missing the patch suffix.
  - Fixes the issue where a newer custom patch version on GitHub (e.g. `v7.1.45-s.5`) was falsely recognized as "older" than a local dev version with a higher upstream semver (e.g. `v7.2.2-s.4`).

- **Full Backward Compatibility**:
  - Maintained full compatibility with existing configurations, loaded Qwen credentials, and usage statistics.
